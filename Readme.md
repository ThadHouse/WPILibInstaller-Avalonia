# WPILibInstaller-Avalonia

Welcome to the WPILibInstaller repository, which hosts the source code used to install the various components, libraries, and applications of the wpilibsuite.

## Generating Installers

### Required Dependencies

- .NET SDK 11.0 or higher.
- Java 17

### Building

An installer can be generated by running the following command:

```
gradlew generateInstallers -PXmx3072m -PlinuxBuild -PjenkinsBuild
```

``-PlinuxBuild`` can be replaced with the OS of your choice to build.

- ``-PlinuxBuild``
- ``-PlinuxBuildArm64``
- ``-PmacBuild``
- ``-PmacBuildArm64``
- ``-PwindowsBuild``
- ``-PwindowsBuildArm64``

If no OS argument is given, it will default to building Windows 64. Additionally, the other gradle options ensure that the build has enough RAM to build properly. It's not recommended to build the installer if your system has less than 4GB of RAM.

### Windows signing

Add `-PwindowsSign` to a Windows build to sign the installer GUI, CLI, shortcut creator,
ToolsUpdater, and their published DLLs with Azure Trusted Signing before packaging the ISO.
PowerShell 7 (`pwsh`) and the .NET 8 x64 runtime must be available, including on Arm64
hosts. The signing script installs the `TrustedSigning` module and verifies each
signature. Files with valid signatures are preserved.

Set these environment variables when signing locally:

- `AZURE_SIGNING_ENDPOINT`
- `AZURE_SIGNING_PROFILE_NAME`
- `AZURE_SIGNING_ACCOUNT_NAME`
- `AZURE_CLIENT_ID`
- `AZURE_TENANT_ID`
- `AZURE_CLIENT_SECRET`

CI enables signing for Windows x64 and Arm64 builds on pushes and manual runs in
`wpilibsuite`. Configure the corresponding `THAD_AZURE_*` GitHub Actions secrets, using
the same names as FirstDriverStation. Pull requests and builds without `-PwindowsSign`
do not invoke signing.

## Organization of repository

This is the organization of the repository directories

- WPILibInstaller.Common (Contains shared installer models, services, utilities, and view models)
- WPILibInstaller.GUI (Contains the Avalonia installer UI)
- WPILibInstaller.CLI (Contains the command-line installer)
- WPILibShortcutCreator (NativeAOT C# utility for creating Windows shortcuts)
- apps (Integrates with Gradle into downloading the various WPILib tools and applications needed)
- files (Miscellaneous script files that are used for VSCode integration, and path handling)
- scripts (Core gradle scripts that download required dependencies)
